// LAB 01 · COMPLETADO · TFG ASIR
Sistema de Detección, Monitorización y Prevención de Intrusos
// Introducción

Diseñé e implementé este laboratorio como Proyecto Final de Grado. Cuatro máquinas virtuales interconectadas forman una infraestructura defensiva completa: el honeypot Chameleon actúa como señuelo sobre servicios simulados, Suricata detecta escaneos, intentos de fuerza bruta y anomalías con reglas ajustadas durante las pruebas, y Wazuh centraliza y correlaciona todos los eventos de seguridad. Un script Python automatiza la respuesta bloqueando IPs via iptables, reduciendo la intervención manual. Todo validado con ataques reales usando Kali Linux, Metasploit e Hydra, mapeando los TTPs al framework MITRE ATT&CK.

// Tecnologías Utilizadas
Honeypot Chameleon
Señuelo desplegado sobre servicios simulados SSH y FTP para atraer y registrar intentos de intrusión.
Suricata IDS
Sistema de detección de intrusos configurado con reglas personalizadas para detectar escaneos, fuerza bruta y anomalías de tráfico.
Wazuh SIEM
Plataforma central que recibe, correlaciona y visualiza todos los eventos de seguridad del laboratorio.
iptables
Firewall basado en reglas que ejecuta el bloqueo automático de IPs atacantes a partir de los logs del IDS.
Python + Bash
Scripts de automatización que extraen IPs del log de Suricata y ejecutan el bloqueo via iptables. Programados con crontab.
Kali Linux
Máquina atacante usada para validar el sistema con Metasploit, Hydra y Nmap simulando ataques reales.
// Instalación y Configuración

Despliegue completo de las 4 máquinas virtuales: Honeypot Chameleon, Suricata, Wazuh e iptables.

// Simulación de Ataques

Ataque SSH — escaneo de puertos y fuerza bruta con Metasploit.

Ataque FTP — escaneo de puertos y fuerza bruta con Hydra.

// Resultados y Detección

Recorrido por los dashboards: alertas en Wazuh, eventos en Suricata, registros del Honeypot y mapeo MITRE ATT&CK.

// Respuesta Automática

Scripts Python y Bash extrayendo IPs del log de Suricata y bloqueándolas automáticamente con iptables vía crontab.
