// Introducción

Este fue mi Proyecto Final de Grado, y la idea era clara: montar un sistema de seguridad real, funcional y sin coste de software, que pudiera aplicarse en una pequeña empresa.

Cuatro máquinas virtuales en VirtualBox, cada una con su rol: el Honeypot Chameleon hace de señuelo exponiendo servicios como SSH, FTP o HTTP para atraer al atacante, Suricata escucha todo el tráfico de la red y lanza alertas con reglas que fui ajustando durante las pruebas, Wazuh recoge y correlaciona todos esos eventos dándome una visión centralizada de lo que pasa, y un firewall con iptables que bloquea automáticamente las IPs maliciosas gracias a unos scripts en Python y Bash que programé para que se ejecuten solos cada pocos minutos.

Para validarlo, lancé ataques reales desde Kali Linux: fuerza bruta sobre SSH con Metasploit y sobre FTP con Hydra. El sistema lo detectó, lo registró y lo bloqueó. Los resultados los analicé y mapeé al framework MITRE ATT&CK.

// Tecnologías Utilizadas
🪤 Honeypot Chameleon
Un honeypot es un sistema trampa diseñado para atraer a los atacantes y obtener información sobre sus métodos. Chameleon es una solución de código abierto y baja interacción que simula servicios y vulnerabilidades típicas de un sistema real, sin ejecutar ningún servicio real por detrás. Su objetivo no es defenderse, sino registrar todo lo que el atacante hace: qué servicios ataca, qué credenciales prueba, desde qué IP llega y cuándo. Esa información es la que luego permite tomar decisiones de seguridad reales.
🔍 Suricata IDS/IPS
Suricata es un sistema de detección de intrusos de código abierto que intercepta los paquetes que viajan por la red y los compara contra una base de reglas actualizada. Cuando detecta actividad sospechosa, una violación de política o un acceso no autorizado, genera una alerta inmediata. Puede funcionar en modo pasivo, solo detectando y registrando, o en modo activo bloqueando el tráfico automáticamente. Cuanto antes se detecta una intrusión, menores son los daños que puede causar.
📊 Wazuh SIEM
Un SIEM recopila y correlaciona eventos de múltiples fuentes al mismo tiempo: servidores, dispositivos de red, aplicaciones. Wazuh hace exactamente eso, recoge la información de todos los agentes que tiene desplegados y la analiza de forma centralizada. Al no depender de una sola fuente reduce los falsos positivos, genera sus propias alertas y permite visualizar todo desde un panel de control. También almacena el histórico de eventos, lo que permite analizar qué pasó antes, durante y después de una intrusión.
🔥 iptables
iptables es un firewall basado en reglas integrado en Linux que filtra todo el tráfico entrante y saliente de la red. Permite crear reglas para bloquear o permitir conexiones según la IP de origen, el puerto o el protocolo. A diferencia de un IDS que solo detecta, el firewall actúa directamente sobre el tráfico, siendo la última barrera que impide que el atacante llegue a los sistemas reales.
🐍 Python + Bash
Python es un lenguaje de programación de código abierto, multiplataforma y muy legible, especialmente útil para automatizar tareas repetitivas y procesar ficheros de texto. Bash es el lenguaje de scripting nativo de Linux, ideal para ejecutar comandos del sistema de forma encadenada. Combinados permiten crear flujos de trabajo automatizados que se ejecutan solos sin intervención manual, reduciendo el tiempo de respuesta ante cualquier amenaza detectada.
☠️ Kali Linux
Kali Linux es un sistema operativo basado en Debian diseñado específicamente para la seguridad ofensiva. Incluye más de 600 herramientas orientadas a pruebas de penetración, análisis de vulnerabilidades, ataques de contraseñas, análisis forense e ingeniería inversa. Es el estándar en el sector para simular ataques reales y comprobar si los sistemas defensivos funcionan correctamente.
